# Сказки — web-часть

**Открыть:** https://olegvyacheslavowich.github.io/skazki/

Интерактивная книжка для детей 2+ лет. Первая сказка — «Репка» (8 страниц).
Слева сцена: тап по персонажу запускает анимацию (тянут-потянут, вытянуть не могут). Справа текст, кнопка озвучки и тихая музыка.

Две версии: русская и английская (переключатель на полке и кнопка `RU`/`EN` на странице, выбор запоминается). В английской версии тап по слову показывает русский перевод в облачке над словом.

Это web-слой будущего приложения **Capacitor + KMP** (вариант 1): web рисует экран, KMP отвечает за звук и данные через Capacitor-плагин `TaleAudio`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173, откройте с телефона по IP из консоли
npm run build      # проверка типов + сборка в dist/ (её потом заберёт Capacitor)
```

Озвучка сейчас идёт через системный TTS браузера (временная заглушка), на языке открытой версии. Если голоса для языка нет, страница «читается про себя»: кнопка вернётся в исходное состояние через оценочное время.

### Новая сказка без кода

1. Папка `public/tales/<id>/` с `tale.json`.
2. Строка в `public/tales/index.json`.
3. Недостающие спрайты — в `art/sprites.ts` (позже будут файлами Rive/PNG внутри пакета сказки).

Для каждой страницы задаются: `scene.elements` (что и где стоит), `groups` (например, `chain` — все, кто тянет), `actions` (что играть по тапу, с задержками, «волной» по группе и звуком). Ошибки в ссылках (нет спрайта, анимации, цели) `TaleRepository` покажет списком при открытии.

### Перевод сказки

Основной язык — `lang` (по умолчанию `ru`). Перевод лежит рядом, в том же `tale.json`:

```json
"translations": {
  "en": {
    "title": "The Giant Turnip",
    "glossary": { "turnip": "репка", "pulls": "тянет", "can't": "не может, не могут" }
  }
},
"pages": [
  { "id": "p2", "text": "Пошёл дед репку рвать…", "translations": { "en": { "text": "Grandpa went to pull the turnip…" } } }
]
```

`glossary` — словарик для тапа по слову: ключ — слово в нижнем регистре без знаков препинания по краям. `TaleRepository` при загрузке проверяет, что у каждой страницы есть текст перевода и что каждое его слово есть в словарике. Название на полке переводится в `index.json` (`translations.en.title`).

### Озвучка записанным голосом

```json
"narration": { "src": "audio/p2.m4a" }
```

Для перевода — так же, внутри `translations.en` страницы: `"narration": { "src": "audio/en/p2.m4a" }`.

## Мост к KMP (следующий шаг)

Контракт — в `src/bridge/TaleAudioPlugin.ts`:

| Метод / событие | Смысл |
|---|---|
| `openTale({taleId})` | нативная сторона читает тот же `tale.json`, предзагружает аудио |
| `narrate({taleId, pageId, lang})` | прочитать страницу на языке `lang` (`ru` / `en`) |
| `stop()`, `pause()`, `resume()` | управление и жизненный цикл |
| `setMusic({enabled})` | фоновая музыка с приглушением во время голоса |
| событие `ended {pageId, reason}` | `completed` / `interrupted` |

Web передаёт только идентификаторы и язык. Тексты и пути к файлам нативная сторона берёт из того же `tale.json`, так что источник правды один.

Как только в нативной сборке зарегистрирован плагин `TaleAudio`, `createAudioService()` сам переключится с web-звука на нативный. UI менять не нужно.

План:

1. `npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios`, `npx cap init`, `webDir: dist`.
2. KMP-модуль `shared`: модель `Tale` (kotlinx.serialization), `TaleAudioEngine` (`expect/actual`: Media3 ExoPlayer / AVAudioEngine), аудиофокус, звонки, фон.
3. Плагин: `TaleAudioPlugin.kt` и `TaleAudioPlugin.swift` — тонкие обёртки над `shared`.
4. Записать голос для 8 страниц на двух языках, заменить TTS.

## Что учтено для детей и мобильных

- Хит-боксы крупнее спрайтов (+28 единиц), реакция на `pointerdown` — без задержки клика.
- Выход в полку только долгим нажатием на «домик» (1,5 с, кольцо прогресса).
- Звук разблокируется первым тапом по обложке (политики автовоспроизведения iOS и Chrome).
- Нет зума, выделения, контекстного меню; учтены safe-area и вырезы экрана.
- Ландшафт: сцена слева, текст справа. Портрет: сцена сверху. Персонажи по бокам не обрезаются; на высокой странице сцена стоит по центру, сверху и снизу продолжаются небо и земля.
- Перелистывание как в книге: всегда справа налево (в портрете лист — весь экран).
- Уход в фон: озвучка останавливается, аудиоконтекст засыпает.
- `prefers-reduced-motion` отключает декоративные анимации.
